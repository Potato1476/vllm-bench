# Mock warehouse (phạm vi tiếp theo)

Thư mục này được giữ cho schema và dữ liệu giao dịch giả lập. Corpus hiện tại đủ để mock retrieval, citation và source versioning. Các câu hỏi yêu cầu số liệu thực thi cần thêm warehouse gồm `fact_bookings`, `fact_trips`, `fact_payments`, `fact_driver_online_sessions`, `fact_driver_offers`, `fact_charging_sessions`, `fact_vehicle_status` và các dimension tương ứng.
